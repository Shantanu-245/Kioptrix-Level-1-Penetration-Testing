## Project Overview

This repository contains my **Kioptrix Level 1 Penetration Testing** assignment completed as part of my Cyber Security practical coursework.

The objective of this project was to perform a structured security assessment of the Kioptrix Level 1 vulnerable virtual machine by following a standard penetration testing methodology. The assessment focused on identifying exposed services, analyzing potential vulnerabilities, documenting observations, and verifying administrative access within a controlled laboratory environment.

---

## Objectives

- Perform reconnaissance and information gathering.
- Identify active hosts and open ports.
- Enumerate running services and software versions.
- Analyze potential security vulnerabilities.
- Verify administrative (root) access in the lab environment.
- Document the complete penetration testing process.

---

## Methodology

The assessment was conducted using the following phases:

1. Information Gathering
2. Port Scanning
3. Service Enumeration
4. Vulnerability Analysis
5. Exploitation (Lab Verification)
6. Proof of Root Access
